**Breaking:** each sync platform takes its app and one sync function, called for every event in both directions: `slack('slack/acme', channels({ '#prs': 'prs' }))`, `github('github/acme', repos({ 'acme/www': 'prs' }))`, `kapso({ adapter, markRead }, numbers({ '16315558151': 'support' }))`. Coming in, the function calls `sync.import(channel?, overrides?)`; going out, `sync.deliver({ render? })`, or `sync.start(channel)` for a new root. One that calls nothing does nothing. `channels`, `repos`, and `numbers` route by platform channel, and `mirror`, `into`, and `render(renderer, fn)` from `vboard/sync` compose under them. A string under `repos` now imports only: what's said on the board or in Slack reaches GitHub only when a function delivers it (`mirror('prs')` sends everything, as before). Replace `channels: { … }` with `channels({ … })`, `{ channel, run }` and `async ({ event, board }) => board.sync(channel, event, overrides)` with a function that calls `sync.import(channel, overrides)` coming in and `sync.deliver()` going out, and the `render` option with `render(renderer, …)`. `SyncHandler`, `EventMapping`, and `SyncClient` are gone; `SyncProvider` takes the function as its constructor's second argument, and `UnreadableError` is exported from `vboard/sync` for a provider's `resolveChannel` to say a channel doesn't exist.
